Smart First Aid Kit – AI + IoT Health Assistant

IoT-powered kit that predicts injury severity and recommends first aid steps using machine learning.

ArduinoPythonScikit-LearnIoT

Injuries during emergencies often go untreated due to lack of medical knowledge. This system uses IoT sensors (temperature, pulse, pressure) to capture real-time health data and feeds it into a trained ML model that classifies injury severity. Based on the prediction, it displays step-by-step first aid instructions on an LCD screen. Built with Arduino for hardware, Python and Scikit-Learn for the ML pipeline, and serial communication between hardware and software.

ML-Based Smart Irrigation System

Predicts optimal watering schedules using soil and weather data with an ML model to reduce water waste.

PythonScikit-LearnArduinoSoil Sensors

Traditional irrigation wastes water by following fixed schedules regardless of actual soil conditions. This system uses soil moisture, temperature, and humidity sensors to collect real-time field data. A trained ML model analyzes the data and predicts when and how much to irrigate, activating the water pump automatically via Arduino. Reduces water consumption while maintaining optimal soil moisture levels for healthy crop growth.

Smart Plant Monitoring & Automation System

IoT system that monitors plant health in real time and automates watering and lighting conditions.

ArduinoESP32SensorsStreamlit

Caring for plants requires consistent monitoring of environmental conditions. This system uses soil moisture, light intensity, and temperature sensors connected to an ESP32 microcontroller to continuously track plant health. When conditions fall outside optimal ranges, it automatically activates a water pump or grow lights. A Streamlit dashboard provides real-time visualization and historical data logging for easy monitoring from any device.

Smart Plant Pot – IoT Plant Monitoring System

IoT-based system that monitors plant health using real-time sensor data.

ESP32Arduino IDESensorsIoTEmbedded Systems

Developed an IoT-based Smart Plant Pot that continuously monitors soil moisture, temperature, and light intensity to ensure optimal plant growth. Integrated sensors with an ESP32 microcontroller to collect real-time data and display it on an OLED screen with visual indicators and animations. Implemented Telegram integration to allow users to request live plant status remotely, making the system interactive and user-friendly. The system reduces manual effort and helps maintain plant health efficiently.
